# Security Policy

SkillGate handles instructions that may influence coding agents, so reports about unsafe skill loading, policy bypasses, command execution, path traversal, secret exposure, and untrusted input are treated as security issues.

Please do not open a public issue for a vulnerability that could put users at risk. Use GitHub's private vulnerability reporting feature when it is enabled for this repository.

Until a stable release exists, only the latest revision on the default development line is supported.

SkillGate should treat discovered skills and repository contents as untrusted input. Discovery and ranking must not execute repository code.
